# Project: fun_online_resume

## Project Overview

An infographic-style, gamified resume site, built/generated with Claude Code. Two parts:
- `/web`: Next.js (TypeScript) frontend, deployed to Vercel at bidamia.ca. This is the actual site.
- Python pipeline (`/src/linkedin_project`, `/scripts`): hand-curated resume content, exported to `web/src/data/resume.json`, which the frontend reads statically at build time. There is no scraper and no database — the content is written by hand in `export_resume.py`. There is no Python runtime in production — the Python side only produces data.

## Important

2. You must write automated tests for all code.
3. You must compile the code and pass ALL tests before committing.
4. Code Reviews: Submit a pull request for code reviews before merging into the main branch.

- **Language**: Python 3.10+
- **Code Style**: Follow PEP 8 strictly, use Black for formatting
- **Type Hints**: Required for all function signatures and class definitions
- **Documentation**: Docstrings required for all public functions and classes

## Workflow Requirements
1. Create feature branch: `feature-datapipeline-[description]` or `feature-visualization-[description]`
2. Write unit tests for all data processing functions
3. Run `pytest` and ensure all tests pass
4. Run `black .` and `flake8` before committing
5. Update relevant documentation in `/docs` if adding new features

##Project Structure
- `/web`: Next.js (TypeScript + Tailwind) frontend — the deployed site, built for Vercel
- `/web/src/app`: App Router pages and layout
- `/web/src/components`: Infographic sections, chart components (hand-rolled SVG where possible, see `mccandless-infobeauty` skill for the visual language), and the arcade mini-games (`Arcade*.tsx`)
- `/web/src/data/resume.json`: Static resume data consumed at build time — generated by `scripts/export_resume_json.py`, not edited by hand
- `/src/linkedin_project`: Main Python package containing the resume content pipeline
- `/src/linkedin_project/pipelines/export_resume.py`: All hand-curated resume content (profile, experience, skills, education, portfolio) — the single source of truth
- `/src/linkedin_project/utils`: Shared helper functions used across modules
- `/scripts/export_resume_json.py`: Writes `web/src/data/resume.json` from `export_resume.py`
- `/tests`: Unit tests for the Python pipeline
- `/.github/workflows`: GitHub Actions workflows for CI (Python pipeline) — Vercel handles frontend build/deploy on push via its own GitHub integration
- `/docs`: Project documentation such as architecture notes

## Data Handling Standards
- Use Pandas for data manipulation, prefer vectorized operations
- Resume content is hand-curated, not scraped — edit `export_resume.py` directly and regenerate with `python scripts/export_resume_json.py`

## Dependencies
- Python pipeline — pandas; Testing: pytest, pytest-cov
- Frontend (`/web`) — Next.js, React, TypeScript, Tailwind CSS; no chart library by default, prefer hand-rolled SVG per [[mccandless-infobeauty]] unless a chart genuinely needs one
