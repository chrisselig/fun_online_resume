# web

Next.js (TypeScript + Tailwind) infographic resume site — the deployed app. See the [repo root README](../README.md) and [docs/](../docs/) for the full project, including how `src/data/resume.json` is generated and how deploys to Vercel work.

```bash
npm install
npm run dev    # http://localhost:3000
npm run test
npm run lint
npm run build
```
